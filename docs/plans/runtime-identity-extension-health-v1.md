# Runtime Identity & Extension Health v1

## Goal

Establish a single runtime identity boundary between Hermes Core, extensions, connectors, and cloud projection.

## Non-goals

- No A2A implementation in this phase.
- No collaboration workflow.
- No Cloud business model changes.

## Runtime Authority

The runtime owner must expose:

- runtime_id
- runtime_generation
- profile
- process identity
- extension health snapshot
